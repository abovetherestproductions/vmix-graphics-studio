Export Stills

What this does checking…
Saves a transparent PNG of each graphic, for every skater in a segment — so you can rebuild a stream that didn't record. Drop the name bar in when a skater is announced and the score panel when the scores are read. The PNGs have a real alpha channel and key straight over video.

The graphics do their own drawing, so a still is exactly what the live graphic looked like. Rendering borrows the live data for a moment and puts it back when finished — safe to run between events, but not during one.
Where the files go
Currently writing to …
Leave it blank and stills go to exports inside the install folder — always writable, and the same on every machine. To send them somewhere else, type the full path: on Windows the app runs as a background service under its own account, so a shortcut like ~/Downloads would land somewhere nobody can find. C:\Users\yourname\Downloads works.
