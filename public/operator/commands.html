Using these with a Stream Deck
Every address below is a plain web link, so a Stream Deck can fire it with the built-in System → Website action — tick Access in background so no browser window opens. No extra software needed.

They also work from Companion (Generic HTTP → GET), from a browser address bar for testing, or from any automation that can fetch a URL.
This machine's address
